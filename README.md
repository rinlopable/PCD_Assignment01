# PCD Assignment 01

This repository contains my Digital Image Processing Assignment 01 about downsampling and upsampling methods.

## Methods Used

### Downsampling
- Max Pooling
- Average Pooling
- Median Pooling

### Upsampling
- Nearest Neighbor
- Bilinear Interpolation
- Bicubic Interpolation

## Files

- `PCD_Assignment01.ipynb` — implementation and experiment
- `PCD_Assignment01_Report.pdf` — analysis report
- `images/` — input images used in the experiment

## Notes

The experiment uses images with different characteristics, including edges & text, a natural scene, and fine details. Downsampling factors of 2 and 4 were tested, while the upsampling comparison uses the Average Pooling result with factor 4 as the low-resolution input.
